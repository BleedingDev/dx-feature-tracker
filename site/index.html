dft

See what each feature cost to build with AI.

dft reads your Cursor and git history on your machine and shows the cost, tokens and time for each branch.

Install

The problem

  • Cursor sends one monthly bill. It doesn't say which branch spent the money.
  • You can't put a feature's cost next to the commits it produced.
  • Run three agents at once and all their usage lands on the same bill.

What you get

A price per branch.
You see what Cursor billed you, Cursor's own cost figure and a list-price estimate, each on its own line. dft never adds them together.
Past work, priced too.
dft reads the Cursor history already on your machine. Work from before you installed it counts toward the branch that was checked out at the time. git keeps 90 days of checkout history by default. dft matches older work by its commits or leaves it unassigned.
Parallel agents kept apart.
An agent working in its own git worktree counts toward that worktree's branch.
Where the money went.
dft splits each branch into tokens by kind, time on the branch, agent time, commits, lines changed, and the model and reasoning level of each chat.

How it works

  1. Install. Run dft install in your repo.

  2. Keep working. Use Cursor as usual. dft's Cursor hooks record each session.

  3. Check the cost. Run dft line for one line or dft analyze for the full report.

One line per branch

Example with made-up numbers:

The line fits in your shell prompt. dft install --git-hooks prints the cost on every commit and push and never blocks them. To block a commit when a branch costs more than $5, put dft snapshot --max-cost 5 in a hook of your own.

Privacy

dft stores its data in ~/.dft on your machine. It talks to cursor.com only to fetch your own usage, and it downloads public price lists from models.dev or LiteLLM. Set DFT_CURSOR_USAGE=off to skip the Cursor import.

Get it

npm i -g https://github.com/BleedingDev/dx-feature-tracker/releases/latest/download/dx-feature-tracker.tgz
cd your-repo
dft install

You need Node 24.18 or later, macOS on Apple Silicon or Linux (arm64 or x86_64), and Cursor.
