## Gaps and findings for the owners

- **Tool-call double count** (flight-time owner): 24 vs 12 here. This is C09 finding 2 again.
- **Shell failure not counted**: a shell hook with `exit_code` 7 gives `failed-commands` null and `tool-calls` 0.
- **Undisclosed collapse**: the duplicate stop hook is collapsed (7 spool files, 6 inserted), but the collect reports `duplicates=0` and `duplicate-rows-collapsed=0`.
- **Rework**: `git.files-retouched` is 1, but `friction.reworked-files` is 0.
- **Still open**: the stale hooks gap `live-capture-not-demonstrated` (B05) and the broken `analyze --flight` (A02/A07). The rehearsal avoids the latter by using repo + current branch.
- **Checker not linted**: the checker code is a node heredoc inside `rehearse.sh`, so oxlint does not cover it. Standalone `.mjs` checkers failed the ultracite fence, so I removed them.
- **Not tested**: the Cursor IDE. CI and PRs are out of scope.
