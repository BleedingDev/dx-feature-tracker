# B23 repo/worktree correlation (ready, tested)

Status: **ready**. Contract `dx.contracts.v1`, digest `sha256:b9623bd4bb6a9b20598a6f0186930153fdf4be77ff40545e03b8e0ba153eb090`.

## What it does

Maps any observed absolute path (Cursor hook `cwd`, `workspace_roots`, edited file paths) to the canonical repository (Git common dir) and the innermost worktree, then fills `FlightContext` (`repoCommonDir`, `worktreePath`, `branch`, `headSha`) without overwriting contradicting context.

## Exports (`packages/core/src/dx/correlation/repo/`)

- `path.ts`: `normalizePath`, `relativeWithin`, `isContained`, `containedJoin`. Segment-aware (`/repo2` is not in `/repo`); `..` traversal and absolute escapes are rejected.
- `worktree-map.ts`: `parseWorktreePorcelain` (`git worktree list --porcelain`), `buildRepoMap`, `resolvePath` (matched / outside / ambiguous / invalid; nested worktrees resolve to the deepest root; paths inside the common dir are not worktree content), `correlateContext`.
- `git-dir.ts` (Effect, needs `FileSystem`; provide `NodeServices.layer`): `discoverGitLocation`, `loadRepoMap`, `repoMapForPath`, `canonicalizePath`. Filesystem-only and read-only: no git spawn, no locks. Resolves loose refs and `packed-refs`; deleted linked worktrees are marked `prunable`.
- `descriptor.ts`: `repoCorrelationDescriptor` (`correlation.repo`, kind `correlation`, readiness `ready`).

## Assignment rules

`assigned` when all matched paths fall in one worktree. `detached` maps repo/worktree but leaves `branch` null. `multi-root` and `conflict` (the event already names another repo/worktree) keep the original context. Nothing matched → `unassigned`. Branch labels are aliases only.

## Integration recipe

```ts
const found = yield* repoMapForPath(selectedRepo);          // once per collect
const cwd = yield* canonicalizePath(hookPayload.cwd);        // realpath (/var vs /private/var)
const { context, assignment } = correlateContext(found ? [found.map] : [], event.context, [cwd]);
```
