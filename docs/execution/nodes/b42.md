# B42 handoff: timeline and evidence drill-down (optional), status DISABLED

A pure view model with fixture tests. It is not a working surface: apps/web is outside the workspace (A01 decision), and nothing renders the module or wires it up.

- Contract: `dx.contracts.v1`, digest `sha256:b9623bd4…eb090`. Consumes `ExplainTimeline`, `EvidenceItem`.
- `apps/web/src/features/dx/b42/timeline-drilldown.ts`: `buildTimelineDrilldown(timeline, evidence)` groups entries into lanes. It keeps the declared lane order and appends undeclared lanes. It sorts dated entries by time and puts undated ones last, with `orderingUncertain` set and a per-lane `undatedCount`. Each evidence ID resolves to the item or shows as `missing`, and `missingEvidenceIds` lists the missing ones. It also returns an `originMix` count and discloses truncation (`nextCursor`/`total` against `shown`). It never fills in missing times or evidence.
- `apps/web/src/features/dx/b42/descriptor.ts`: `timelineDrilldownDescriptor` (id `surface/timeline-drilldown`, kind `surface`, readiness `disabled`, with gaps listed).
- Test `apps/web/test/dx/b42.test.ts` covers fixtures `b42-timeline-multi-lane`, `b42-timeline-missing-time` and `b42-timeline-truncated`, and decodes the descriptor with `ModuleDescriptorSchema`.
