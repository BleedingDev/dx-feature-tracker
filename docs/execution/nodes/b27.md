# B27 interval helpers: handoff

Status: **ready**. Contract `dx.contracts.v1`; implements the frozen `IntervalHelpers` from `packages/core/src/dx/model/interval.ts`.

## What exists
- `packages/core/src/dx/metrics/intervals/intervals.ts` exports `intervalHelpers` (`union`, `sum`, `overlap`), plus `classifyInterval`, `closeOpenIntervalAt` and `intervalsDescriptor` (`dx.metric.intervals`, readiness `ready`).
- Censored: a null or non-finite start/end. It is left out of the arithmetic and counted. Clock error: end before start. It is also left out and counted. Zero-length intervals count as valid.
- `union` merges overlapping and touching intervals and deduplicates evidence IDs. It works for branch active time and wall-clock coverage.
- `sum` adds up valid durations without merging them, so overlaps count once per interval. It works for summed agent time across parallel sessions.
- When there is no valid interval, `totalMs` is `null` (unavailable), never 0. When `censored` or `clockErrors` is above 0, the total is a lower bound, and the counts must be shown next to it.
- `closeOpenIntervalAt(interval, nowMs)` gives "branch start to now". It closes an interval that has a known start and no end, and adds `@as-of` to its label.
