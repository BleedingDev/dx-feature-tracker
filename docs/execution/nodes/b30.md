## What exists
- `packages/core/src/dx/metrics/ai-usage/normalize.ts`: parses usage payloads with Effect Schema into rows (ledger, category, method, currency, match keys, detail/aggregate scope) plus an uncovered list.
- `ledger.ts`: `accountAiUsage(events)` / `accountAiUsageByBranch(events)`: dedup via request/turn match keys (union-find across sources), per-slot `AI_SOURCE_PRECEDENCE`, `OverlapGroup`s (collapsed / alternative / unresolved), aggregate ledgers kept as alternatives, unkeyed conflicting rows left unassigned.
- `metric.ts`: `aiUsageMetric: DxMetric` with descriptor `dx.metrics.ai-usage` (ready). Token categories, money ledgers (charge, metered, list-price-estimate with method `estimated`, unallocated), requests, duplicates collapsed, uncovered, unresolved, aggregate-alternative tokens. Missing values are `unavailable` with a reason.

## Repair (C05, 2026-09-30)

- Unkeyed detail rows are deduplicated by `evidenceId`+slot, so an identical re-import counts once.
- Sessionless `request:<id>` keys are bridged to the single matching `session:<s>:id:<id>` key. When the id matches more than one session, the row goes to `unresolved` and is not summed.
- `accountAiUsageByBranch` attributes each request group to one branch. It uses the only known branch if there is one, otherwise the branch of the highest-precedence source. If that is still ambiguous, the group goes to `(no branch)`. Per-branch totals now add up to the global ledger.
