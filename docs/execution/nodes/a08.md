# A08 handoff: enabled-adapter admission (optional)

Status: **degraded**. The admission policy is done and tested, but it is not wired into the CLI or composition yet.

## What exists
`packages/core/src/dx/registry/admission.ts` (pure, no Effect services):
- `admitDescriptors(descriptors, { requireFixtures? })` admits only `ready`/`degraded` descriptors on `CONTRACT_VERSION`. It rejects `not-ready`, `contract-mismatch`, `duplicate-id` and `missing-fixture`. `listed` still holds every descriptor, including disabled ones, so status can show them.
- `enabledDescriptorRefs(result)` returns `{id, version}[]` for `snapshot.enabledDescriptors`.
- `snapshotCompatible(snapshotRefs, current)` returns false when any descriptor the snapshot used is no longer admitted at the same version. Callers must then report the stored snapshot as it is and must not recompute it.
- `eligibleNodes(statuses)` returns the node IDs whose handoff is `ready`/`degraded`, as input for the G03 freeze.

Test: `packages/core/test/dx/integration/a08-admission.test.ts` (4 passed, exit 0). Lint, format and typecheck are clean for A08 paths.

## Integrator wiring (A02/A07 or G03)
In composition, pass every collector `descriptor` through `admitDescriptors`. Register only `result.admitted`, and have `dx_status` show `result.listed`. Before recomputing a snapshot, check `snapshotCompatible`.
