# B13 handoff: OpenCode export importer (optional, status: degraded)

Contract `dx.contracts.v1`, digest `sha256:b9623bd4bb6a9b20598a6f0186930153fdf4be77ff40545e03b8e0ba153eb090`.

## What works
`packages/core/src/dx/collectors/opencode/collector.ts` exports `opencodeCollector` (`DxCollector<FileSystem.FileSystem>`), `opencodeDescriptor` (`collector/opencode`, readiness `degraded`), `OPENCODE_ADAPTER_ID = "opencode"`, and pure `parseOpencodeExport` / `importOpencodeExport`.

Input: a user-selected file from `opencode session export --sanitize <sessionId> > file.json`. The OpenCode database is never opened.

Output per export:
- one `ai.session` event (message counts, directory, parent session, updatedAt)
- one `ai.usage` event per assistant message: source-reported tokens (input, output, reasoning, cacheRead, cacheWrite; `null` when absent, `total` always `null`), cost as `list-price-estimate` / `estimated` in USD, tool call count plus names from tool parts, duration, model/provider, canonical `requestKey` / `turnKey`.
- Coverage is `complete`, `partial` (some usage fields missing, gap `missing-usage-fields`) or `none`.

Errors: no input -> `InvalidInput`; unreadable -> `SourceUnavailable`; bad JSON -> `InvalidInput`; foreign shape -> `UnsupportedSource`.
