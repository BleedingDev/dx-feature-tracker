  - `model` from `system init`, `identity.sessionId` and `requestId`, and `requestKey = source:cursor-cli:request:<id>`.
  - `worktreePath` fallback from `cwd`.

  `charge` and `listPriceEstimateUsd` are always null. Prompts, assistant text, results and tool arguments are dropped, and a canary test checks this. If a `result` has no `usage`, tokens are null with a reason, and the batch gets the `result-without-usage` gap.
- **Unsupported layout:** if the input is a SQLite CLI chat store (`~/.cursor/chats/.../store.db`, protobuf blobs), the collector emits no events and returns coverage `unsupported` with the gap `cli-store-db-unsupported`. That directory does not exist on this host.
