# C13: installer (ready)

`scripts/dx-install.ts` wires the recorder into one selected Cursor project. It installs the MCP server (v0), the skills (v0) and the project hooks (v1). It backs up every file before changing it, and `uninstall` removes only what it added. It never touches `~/.cursor`. User guide: [docs/install.md](../../install.md). Config shape: [install-config.json](../install-config.json).

## What it does

- **`mcp.json`:** adds `mcpServers["rat-stack"] = <node> <recorder>/apps/cli/dist/cli.js mcp`, with `env.DX_REPO=<target>` and an optional `DX_STORE`. It refuses to replace a foreign `rat-stack` entry.
- **`hooks.json`:** appends `<node> <cli> dx hook` to 11 events. User hooks are kept. A re-install adds no duplicates and replaces a stale command from an earlier install.
- **Skills:** copies `dx-analyze` and `dx-explain` into `<config-root>/skills/`.
- **Ignore rule:** adds `.dx-flight-recorder/` to `.git/info/exclude`.
- **Bookkeeping:** writes the ownership manifest `dx-flight-recorder.install.json` and `*.dx-backup-<ts>` copies.
- **Refusals:** refuses invalid JSON without changing the file.
- **`--config-root`:** lets the tests use an owned fixture directory instead of `HOME`.
