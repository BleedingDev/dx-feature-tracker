# B37 handoff: evidence redaction and bounded source refs

Status: **ready**. B37 is a pure report module over EventStore snapshots, so it needs no source producer. Contract `dx.contracts.v1`, digest `sha256:b9623bd4bb6a9b20598a6f0186930153fdf4be77ff40545e03b8e0ba153eb090`.

## What exists

- `packages/core/src/dx/reports/evidence/resolve.ts`
  - `lookupEvidence(store, { evidenceIds, snapshotId, asOf, selector, mode? })` reuses B35's `selectAnalyzeSnapshot`:
    - A requested `snapshotId` is pinned. An unknown one fails with `SnapshotNotFound` and is never swapped for the latest snapshot.
    - With no `snapshotId`, it returns the actual latest ID and says so in `disclosures`.
    - It returns `{ snapshotId, items: EvidenceItem[], missing, disclosures }`.
  - `resolveEvidence(snapshot, ids, mode)` is the pure core. IDs match `eventId` first and fall back to `evidence.hash`. At most 100 IDs are handled per call. Every ID that is not returned is listed in `missing` with a reason: `unknown-in-snapshot`, `invalid-id` or `over-limit`.
- `packages/core/src/dx/reports/evidence/redact.ts`
  - `redactText` removes GitHub, OpenAI and Slack tokens, AWS keys, JWTs, Bearer/Basic credentials, `password=`/`api_key=`-style pairs, private keys and emails. It also collapses `/Users/<name>` and `/home/<name>` to `~`.
  - `boundRef` strips control characters and URL userinfo, query and fragment, redacts secrets and caps the ref at 240 characters.
  - `excerptPayload` builds a metadata-only excerpt:
    - Numbers, booleans and nulls are kept, so missing values still show as `null`.
    - Content-bearing keys are withheld and only their length is shown. These include prompt, text, command, stdout, diff and similar keys.
    - Values under secret-named keys are replaced with `[redacted]`.
    - Arrays show only their length. Nesting is followed 2 levels deep, with at most 24 fields. Each field is capped at 120 characters and the whole excerpt at 512.
    - A payload that is not JSON is withheld.
  - Any change sets `redacted: true`.
- `descriptor.ts` holds `evidenceReportDescriptor`: id `dx.report.evidence`, kind `report`, readiness `ready`.

## Gaps

- The frozen `DxEvidenceOutput` has no field for `missing` or `disclosures`. Either A03 adds an optional field, or the CLI renders them.
- Redaction matches known secret patterns only. A secret in an unrecognised format inside a non-content metadata string could pass through. Content keys are always withheld.
- There is no mode that returns raw content.
