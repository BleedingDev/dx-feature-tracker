## Input

`selectedInput` = a file or directory (non-recursive). `.xml` → JUnit, `.json` → vitest/jest JSON, `.jsonl` → command sessions:

```json
{"schema":"dx.local-test.command.v1","sessionId":"cmd-1","argv":["pnpm","vitest","run"],"cwd":"...","branch":"feature/x","headSha":"...","startedAt":"ISO","endedAt":"ISO","exitCode":1,"reports":["junit.xml"]}
```

Null selectedInput → `InvalidInput`; unreadable path → `SourceUnavailable`. Event IDs are sha256(adapterId, upstreamKey, kind); reports keyed by content hash, so re-import dedupes.

## Join rules

1. Exactly one session lists the report basename in `reports` → `strong` (`declared-report`).
2. Else report timestamp inside exactly one session's `[startedAt, endedAt + 5s]` → `provisional` (`time-window`).
3. Else `unassigned`. Ambiguity never picks a winner. A joined report takes the session's branch/headSha.

## Privacy

Argv is redacted (`token|secret|password|api_key|auth...=` values → `[redacted]`) and capped at 200 chars; failing test names capped at 25 × 200 chars; no stdout/stderr, hostnames or failure messages are stored.
