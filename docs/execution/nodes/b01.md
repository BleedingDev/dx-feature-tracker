# B01 handoff: SQLite event store

Status: **ready**. Contract `dx.contracts.v1`, digest `sha256:b9623bd4…eb090`.

## What exists

- `packages/core/src/dx/storage/sqlite-event-store.ts`: `EventStoreService` on `node:sqlite`. `SqliteEventStoreLayer({ path, kind })` provides `EventStore` (scoped; the DB closes on release).
  - Single writer: WAL, `BEGIN IMMEDIATE` per write, `busyTimeoutMs` (default 5000). A lock held by another writer gives `StoreBusy`.
  - `append` does `INSERT OR IGNORE` by `eventId` and returns `{inserted, duplicates}`. It records coverage per batch, scoped to the batch's flight/repo/branch set. Batches with no events (unavailable sources) stay globally visible.
  - `snapshot(selector)` filters on flightId/repoCommonDir/branch/from/to and orders by `(occurredAt ?? observedAt, eventId)`. The watermark is `events:<n>:<sha256 of sorted ids>`. `snapshotId = snap_<sha256(digest, selector, watermark)>`, so identical input gives an identical ID and events regardless of append order.
  - `putSnapshotManifest` freezes event membership in `snapshot_events` along with coverage. The call is idempotent. A differing manifest under the same ID fails with `snapshot_conflict`, and a stale watermark fails with `watermark_changed`.
  - `getSnapshot` returns frozen members and is never recomputed. It fails with `SnapshotNotFound` and a message prefixed `unknown_snapshot`, `expired_snapshot` (members removed) or `incompatible_snapshot` (contract digest differs).
  - Store kind (`live`/`replay`) is written in `store_meta`. Opening a live file as replay (or the reverse) fails with `StoreError`.
- `migrations.ts`: versioned via `PRAGMA user_version`. A newer on-disk schema is refused.
- `store-path.ts`: `resolveStorePath`. Precedence is `--store`, then `$DX_STORE` (live only), then `~/.dft/{dft,replay}.db`. Also provides `spoolDirFor`.
- `spool.ts`: `writeSpoolBatch` writes atomically (tmp + rename) for hook processes. `drainSpool` imports `*.batch.json` into the store and moves each file to `done/` or `rejected/`.
- `descriptor.ts`: `eventStoreDescriptor` (`service/event-store-sqlite`, ready).
