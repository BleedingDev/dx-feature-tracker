Status: **ready** (handlers tested against a real SQLite store with fixtures; CLI/MCP registration is A02/A07).

## What exists

`packages/core/src/dx/cli/commands/` (no barrel; import modules directly):

| Command | Handler | Behaviour |
|---|---|---|
| start | `runStart(env, {context, flight?, label?, occurredAt?})` | Appends a manual `marker.start` (user-claimed) for the branch context. |
| collect / import file | `runCollect(env, collectors, {context, source, input})` | Requires an explicit source (descriptor id or adapter id); unknown -> `UnsupportedSource`, missing -> `InvalidInput`, disabled/unsupported -> `UnsupportedSource`. `input != null` -> origin `imported`. `StoreBusy` -> batch spooled atomically next to the store (`spooledTo`). |
| import (spool) | `runImportSpool(env)` | Drains the spool through B01 `drainSpool` (idempotent by eventId). |
| analyze | `runAnalyze(env, metrics, {selector, snapshotId, asOf})` | Pinned/as-of/latest via B35 `selectAnalyzeSnapshot`; persists the manifest (non-pinned) so explain can reuse `snapshotId`; composes with disclosures (latest discloses changed evidence); writes cached report `<storeDir>/reports/<snapshotId>.analyze.json` + `latest.json` pointer; returns `reportPath` and `snapshotId`. Unknown pinned id fails `SnapshotNotFound`, never substitutes latest. |
| explain | `runExplain(env, {selector, snapshotId, asOf, cursor, limit})` | B36 timeline; unknown/expired/incompatible snapshot returns `status: "snapshot-unavailable"` with `problem`. |
| status | `runStatus(env, descriptors, selector)` | `StatusReport` + `cachedReport {reportPath, snapshotId, writtenAt}` + `latestSnapshotId` + coverage. |

`env` is `DxCommandEnv {store: EventStoreService, storePath}`; `selectorFromContext(FlightContext)` makes a per-branch selector.

Descriptor: `cliCommandsDescriptor` (`surface/cli-commands`, ready). Fixture: `b38-branch-flight` (`test/dx/fixtures/b38/*.batch.json`, 3 + 1 events on `feature/b38-demo`).
