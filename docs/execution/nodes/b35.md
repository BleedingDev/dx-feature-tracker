# B35 handoff: deterministic analyze report

Status: **ready** (core). Contract `dx.contracts.v1`.

## Exports
- `packages/core/src/dx/reports/analyze/layer.ts`: `analyzeReportDescriptor` (`dx.report.analyze`, report, ready), `ReportComposerLive` (Layer for `ReportComposer`).
- `compose.ts`: `analyzeReportComposer: ReportComposerService`, `composeAnalyzeReport(snapshot, outputs, disclosures?)`.
- `select.ts`: `selectAnalyzeSnapshot(store, { selector, snapshotId, asOf })` -> `{ snapshot, mode: pinned|as-of|latest, disclosures }`. Pinned unknown ID fails with `SnapshotNotFound` (never substitutes latest). Latest discloses its actual ID and whether evidence changed vs the previous stored snapshot (watermark compare). Pass `disclosures` into `composeAnalyzeReport` so they head `notes`.

## Behaviour
- Never recomputes arithmetic; values pass through.
- Deterministic: order/duplication of inputs does not change output (tested by permutation + duplicate output).
- Honesty repairs: null value without reason -> unavailable + reason; value with unavailable/unsupported/disabled measurement -> value withheld; `method: estimated` + `measured` -> `estimated`. Each repair noted.
- Conflicting results for the same metric key are all kept and noted, never summed.
- Notes disclose branch/flight selector, fixture/synthetic/replay origin mix, non-complete coverage gaps, unavailable/estimated/partial metrics, findings referencing absent metrics.
