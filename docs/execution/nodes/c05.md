## Repair (2026-09-30)

All three B30 defects are fixed in `packages/core/src/dx/metrics/ai-usage/ledger.ts`. The C05 tests now assert the correct values:
1. Unkeyed duplicate import: identical rows are deduplicated by event ID and slot (event IDs are content-derived). Input is now 9, `duplicateRowsCollapsed` is 2 and `requestCount` is 1.
2. Branches: each request group is attributed to exactly one branch. If the group has one known branch, that branch is used. Otherwise the branch of the highest-precedence source wins. If that is still ambiguous, the group goes to `(no branch)`. The per-branch sum is now 107 and matches the global ledger. `main` no longer appears in the mixed scenario because its only request is attributed to `feature/a` via the sdk source.
3. Key join: a sessionless `request:<id>` row is bridged to `session:<s>:id:<id>` when exactly one session carries that id. When several sessions carry it, the row goes to unresolved and is never summed. Input is now 500, `requestCount` is 1, dashboard-json is preferred and the 0.3 charge is kept.

B31 check: cost metrics pick a single source kind per ledger (`selectPreferredSource`), so money and tokens are not summed across sources and defect #3 does not reproduce there. Open B31 risk (not fixed, outside this repair's scope): `costByBranch` selects the source per branch after grouping by the raw event branch. A request reported by different sources on two branches can therefore still appear in both branch buckets.
