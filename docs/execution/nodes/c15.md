# C15 handoff: claims audit (ready)

This audit checks that every number the recorder reports has evidence behind it, and that the product never claims savings, productivity, human waiting or AI ownership.

```bash

bash docs/execution/c15/audit-claims.sh <analyze.json> <explain.json> <live|fixture> ...        # audit any other flight
```

The claim ledger and the forbidden-wording patterns are in `packages/core/test/dx/fixtures/c15/claims.json`. Contract digest: `sha256:b9623bd4…eb090`.

## What it checks (on each analyze/explain pair)

- A metric with no value is not marked measured and gives a reason. A metric marked unavailable has no value.
- No money value is an evidence-free 0.
- Every estimate uses `method=estimated` and names its method with `method=`.
- Every source-reported value cites evidence, and that evidence resolves in explain.
- No metric reports savings, productivity, ROI or human waiting.
- No AI survival or ownership value appears without lineage evidence.
- Branch age, active time and agent time are separate metrics.
- Every source with partial coverage is named in the notes.
- The shipped source (`apps/cli/src`, `packages/core/src/dx`) has no causal or productivity wording. Negated disclaimers are allowed.

Negative test: I ran the audit on a copy of the live output with three planted problems (charge=0, a `time-saved` metric and an unlabelled estimate). It found 4 failures and exited 1.
