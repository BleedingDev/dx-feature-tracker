- `packages/core/test/dx/b40.test.ts`: static routing checks against the frozen contracts.

Both skills carry a machine-readable `json dx-routing` block. They also carry these honesty rules:
- Do not recompute any value.
- Missing data is shown as "unavailable".
- Never call `dx_collect` or `dx_mark`.
- Never show raw prompts.
- CI and GitHub are out of scope.

## What the test checks
- The frontmatter `name` matches the directory, and the description is 1024 characters or less.
- The routed tool is a real `CapabilityNames` member.
- The routing inputs equal the contract's input fields exactly (`DxAnalyzeInput`, `DxExplainInput`). No reserved `json` or `yes` fields are used.
- Every `dx_*` token mentioned in a skill is a real capability.
- The preflight tool is read-only, and every tool in `neverCalls` is a mutation.
- The two skills route to different tools.
- If the contract changes, this test fails.
