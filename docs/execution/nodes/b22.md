## Semantics

- Kinds: `start | stop | wait-start | wait-stop | claim` -> `marker.<kind>`. Claim needs a label.
- Flight: explicit `flight` > `context.flightId` > `branch:<sha12(repoCommonDir)>:<branch>` > `InvalidInput`.
- Honesty: every marker payload says `method: "user-claimed"`; live `occurredAt` is `observed` (recorder clock), imported is `user-claimed`. Open intervals stay censored (end `null`), never "now". Waiting is never inferred.
- Import format (`dx.manual.marker.v1` JSONL): `{"schema":"dx.manual.marker.v1","kind":"start","at":"ISO","flight?","branch?","headSha?","label?","note?"}`. Bad lines become coverage gaps; duplicates collapse by deterministic eventId.
