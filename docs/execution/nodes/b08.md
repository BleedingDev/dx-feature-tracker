# B08 handoff: Cursor usage export (CSV) collector

Status: **degraded** (tested; fixture-only, no real export on host). Contract `dx.contracts.v1`, digest `sha256:b9623bd4…eb090`.

## What it does
`cursorUsageExportCollector` imports one explicitly selected Cursor dashboard usage CSV (`selectedInput`), emitting one `ai.usage` event per row (`adapterId cursor-usage-export`, `sourceKind usage-csv`, acquisition `file-import`).

- Header variants: `Date,Kind,Model,Max Mode,Input (w/ Cache Write),Input (w/o Cache Write),Cache Read,Output Tokens,Total Tokens,Cost`; legacy `Date,Model,Input,Output,Total Tokens,Cost ($),Requests`; team exports with `User`/`Email` (dropped, never stored); BOM, quoted cells, thousands separators.
- Tokens: normalized `payload.tokens` plus raw `payload.rawTokens` keyed by the source column name.
- Cost semantics: `payload.costUsd` = raw cell; `payload.costLedger` = `charge` (Usage-based/On-Demand), `metered` (Included), `not-charged` (`… Not Charged`), `unallocated` (unknown kind). Only `charge` populates `payload.charge`. `Included` cell -> costUsd null.
- Rejected rows (column-count mismatch, unparseable date, non-numeric token, unparseable cost) are counted and listed by line number in coverage gap `rejected-rows`; no content.
- Batch identity: `payload.batchId` = sha256 of file = `coverage.watermark`. Event IDs are content-derived (`row:<hash>#<occurrence>`) so re-importing overlapping exports dedupes; identical rows stay distinct via occurrence index.
- Unassigned: CSV has no branch/request/session id, so `context.branch=null`, `requestKey=null`, `payload.attribution=unassigned` (input context branch is deliberately not stamped on).
- Coverage: complete / partial (rejects or zone-less timestamps) / none; window from/to; gaps for unknown columns, missing tokens/cost.
- Errors: no selection -> `InvalidInput`; unreadable -> `SourceUnavailable`; unrecognized header -> `UnsupportedSource`.
