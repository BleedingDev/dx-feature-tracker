## What is verified
- **Launch and handshake:** protocol 2025-06-18, all six `dx_*` tools with input schemas, and `dx_status` decodes.
- **Protocol-only stdout:** across collect, mark, analyze, an unknown snapshot, an unknown tool and a malformed call, 0 non-JSON-RPC lines.
- **Cancellation:** cancelling an in-flight id or an unknown id leaves the server alive, and `ping` and `dx_status` still answer.
- **Bounded pagination:** explain `limit` is limited to 1..500, and the cursor works across a restart and differs per page. A forged cursor is rejected. Evidence takes 1..100 IDs.

## Findings and gaps
- (low, A02/stdio layer) When stdin hits EOF, the server exits 130 and drops requests still in flight. Normal MCP hosts keep stdin open, so they are unaffected.
- The suite skips if `apps/cli/dist/cli.js` is missing, and turbo's core `test` does not depend on the cli `build`. A gate must build first.
